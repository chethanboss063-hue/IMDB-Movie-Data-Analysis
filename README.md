# IMDb Movie Data Analysis

## Project Overview

This project performs exploratory data analysis on an IMDb movie dataset using Python. The analysis explores movie ratings, genres, directors, actors, runtime, votes, revenue, and Metascore.

## Objectives

- Explore and understand the IMDb movie dataset.
- Identify and handle missing values.
- Check for duplicate records.
- Analyze movie ratings, votes, revenue, runtime, genres, directors, and actors.
- Perform additional analysis on the dataset.
- Visualize important findings using charts.
- Derive meaningful insights from the data.

## Dataset

The original dataset contains:

- 1,000 movie records
- 12 attributes

After removing records containing missing values, 838 records remained for analysis.

## Key Findings

- The dataset initially contained 1,000 movies.
- After data cleaning, 838 movie records remained.
- No duplicate records were found.
- There were 277 Action movies in the cleaned dataset.
- The Dark Knight had the highest IMDb rating of 9.0.
- Star Wars: Episode VII - The Force Awakens had the highest recorded revenue of 936.63 million.
- The Dark Knight had the highest number of votes.
- The correlation between IMDb rating and revenue was approximately 0.217.
